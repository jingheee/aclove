# aclove匿名版

## 项目基本信息

项目名称： aclove匿名版
一句话描述： 一个基于gin和vue3的高性能匿名版
主要语言/技术栈： golang, gin, postgresql, redis ，minio,vue3, navieui ,vite，vuerouter

## 项目结构
服务端：backend
前端：frontend/aclove

## 数据库
1. 主键ID统一使用雪花ID
2. 所有类都有统一的id，created_at，updated_at，deleted_at字段

## 服务端
1. 所有数据库模型都使用gorm-gen生成
2. 服务端url为localhost:8888

## 代码规范
1. 命名与结构

- 命名要清晰、准确、完整表达意图（动词+目的）
- 函数短小（<100行最佳），只做一件事
- 单一职责、避免魔法数字、避免重复代码（DRY）

2. 代码质量底线

- 生成代码要求符合需求，不产生逻辑错误和BUG
- 修改代码遵循最小化改动，不引入新的BUG
- 优先使用现代语言特性（可选链、解构等）
- 异常处理要明确，不要吞异常或只返回错误码
- 所有对外输入必须校验/清理（防注入、溢出等）

3. 注释原则（少而精）

只写“为什么”而非“做什么”：

- 业务规则、权衡取舍、复杂算法意图
- 非常规写法的原因
- 临时方案 / TODO / 待优化点要写明期限或负责人

禁止：

- 写“做什么”的低质量注释
- 注释与代码长期不一致

4. 日志规范

- 必须使用结构化日志（JSON 优先）
- 标准日志级别：DEBUG / INFO / WARN / ERROR
- 关键场景必须打日志：
  - 服务启动/停止
  - 重要业务操作
  - 所有异常（含堆栈）
  - 性能关键点（如慢查询、超时）
- 禁止：打印明文密码、token、身份证等敏感信息
